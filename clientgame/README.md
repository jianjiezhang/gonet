# 反向贪吃蛇（单机客户端）

纯浏览器游戏。没有游戏服务器。`npm run dev` 只是在本机起一个静态网页进程，把页面发给浏览器，对局逻辑都在浏览器里跑。

## 环境

需要 Node.js 20 或 22（带 npm）。若终端里找不到 `node`：

```bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
```

确认：

```bash
node -v
npm -v
```

## 第一次

在本目录安装依赖（只需做一次，或 `package.json` 变了再做）：

```bash
cd clientgame
npm install
```

## 开发运行

```bash
cd clientgame
npm run dev
```

终端里会出现 `Local: http://127.0.0.1:5173/`。用浏览器打开这个地址。

改 `src/` 下的代码会自动刷新页面。用 `Ctrl+C` 停掉这个进程。

## 操作

开局选择玩法。

### 玩法 1 · 猎人追逐

- WASD / 方向键：移动
- 空格：冲刺
- Enter 或点击：开始 / 死后重开
- Esc：回模式选择

地图比屏幕大，镜头跟着你；左上角是小地图。碰到蛇头即死，蛇身是墙。蛇靠近后会预警并锁定扑咬——看红格侧闪，扑空后它会硬直。把它引进身体或边界可断身。金色果子：你吃加速，蛇吃变长。

### 玩法 2 · 猎场信使

- 3 分钟内按顺序站上信标 A → B → C（每站约 1 秒）
- 青绿色安全区可躲蛇头，但会：庇护 → 不稳 → 瓦解 → 消失换位
- 最后一站不能在安全区内完成
- 场上有 4 个猎物机器人同跑；你完成即过关，名次只影响观感/分数
- Esc：回模式选择

## 其它命令

```bash
npm run build    # 检查类型并打出 dist/ 静态文件
npm run preview  # 本地预览打包结果
```

`dist/` 可以放到任意静态托管上打开，仍然不需要游戏服。
